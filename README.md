# Deformation-Aware Mesh Refinement for Robust Automatic Rigging

**Hyun Wook Kim · Sanglim Han · Hak Gu Kim**  
Chung-Ang University, South Korea

[Project Page](https://cau-irislab.github.io/Deformation-Aware-Mesh-Refinement/) · [Code](https://github.com/Budy123/Deformation-Aware-Mesh-Refinement)

Mesh refinement that considers surface orientation and skinning weights when
merging duplicate vertices, preserving double-sided structures while reducing
deformation inconsistencies.

This repository hosts the project page. The implementation, example data,
and evaluation tools are available in the [code repository](https://github.com/Budy123/Deformation-Aware-Mesh-Refinement).
